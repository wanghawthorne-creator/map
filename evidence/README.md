# Evidence register / 证据目录

查阅基准：2026-11-16（Asia/Shanghai）。[sources.json](sources.json) 是来源目录，[claims.json](claims.json) 将来源关联到每项主张，再由地点记录和C01引用。URL可变，定位使用标题和段落主题，不依赖本工具行号。

首条地点的公开地理依据只有 E-PUB-001。没有把同一报道的转载或本地文章当成第二个独立来源；目前不能声称完成多来源地点验证。E-LOC-001/002只支持材料恢复与方法限制，不用于确定点位。2026-11-16用户直接提供的三张原图另建E-IMG-001/002/003，文件哈希和尺寸见 [materials.json](../data/materials.json)；它们与旧归档副本不按字节视为同一文件，也不取代旧记录。提供日不等于拍摄/制图日。

| 证据类别 | 当前状态 | 允许的结论 |
|---|---|---|
| 实地观察 | 未导入可公开、带日期的原始观察记录 | 不能写本项目已现场核验 |
| 本人回忆/自述 | 本次背景陈述；细节待本人确认 | 说明经历背景，不替代现场凭证 |
| 公开来源 | E-PUB-001正文已读 | 标明“来源在当时报道”，不承诺现状 |
| 历史材料 | 两截图、手绘图及部分转写实际已读；不随包复制 | 可说明资料种类、缺陷与待补证 |
| 推断 | CL-003宽泛功能类别 | 标明是据报道推断，不当注册分类 |
| 模拟 | 当前无模拟地点数据 | C01的查询场景是自拟评估练习，不是平台抓取或官方考题 |

公开招聘和技术资料链接分别在 [roles](../docs/roles.md)、[methods](../docs/methods.md)；地名调查的已读/摘要/读取失败记录见 [name-check](../docs/name-check.md)。

未保存第三方新闻全文、照片或网站镜像。私人原件位置、授权凭证和身份信息留在本地工作记录，不进入候选公开包。以后每次补证保留：来源ID、产生日期、查阅日期、原串、校订建议、理由、复核者和版本，不覆盖冲突来源。
