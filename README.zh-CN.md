# 老太沟地图与搜索质量评估案例

[English](README.md) · 审阅草稿 v0.2 · 2026-11-16 · [浏览页面](site/index.html)

这是个人独立作品集，与 OneForma 不存在本项目所声称的雇佣、合作或背书关系。不使用招聘考试题、保密指南或客户数据。评分规则是本项目自建规则。

当前包含：材料盘点、官方岗位核对、一条来源可追溯的地点记录、英中浏览页面、三张原图的来源元数据、五个明确分类的自拟查询练习、字段说明、证据目录、问题日志和可运行检查。**不是五个独立实测案例，也不是已配准的导航地图。** C01/C03共用报道，C02/C04展示证据边界，C05仍待现状补证。用户于2026-11-16看过预览和审阅包后，确认将此草稿提交至公开仓库 `wanghawthorne-creator/map`；此次不启用Pages，也不表示地理事实或原图权利已获核实。

页面支持三种材料切换、本机选图、缩放、案例与地点记录查看。原图不进入Git；本地原图审阅通过独立回环服务器加载，不把图中标签中心当书苑坐标。尚不能保证原图的公开转载许可，手绘作者与私人地点标签也待审查。

首记录的名称来自2026-08-14公开报道，2026-11-16查阅。报道提到“老太沟书苑”，区位写“大理海东镇老太箐村”。这能支持报道时点的名称和宽泛文化功能，不能证明两个地名等同，不能确认当前行政村、精确坐标或现在仍运营。

一分钟阅读 [首个案例](cases/C01.md) 和 [地点记录](data/places.json)；五分钟再查看 [证据链](evidence/README.md)、[质量问题](quality/issues.json)、[岗位能力对应](docs/roles.md) 和 [最小可行方案](docs/mvp-plan.md)。

你在田野观察、志愿活动、访谈和地方记录方面的经历，当前依据是本次自述。具体分工、日期及图像权属待你核实。AI协助了检索、文件盘点、结构设计、评估草拟、英文说明和校验代码；这些不等同于你已经独立掌握GIS、编程或专业评分。

本地运行（Python 3.10+，不需安装依赖）：

```sh
python scripts/qa.py
python -m unittest discover -s tests -v
python -B scripts/build_site.py
python -B scripts/check_site.py
python -m http.server --bind 127.0.0.1 --directory . 8765
```

打开 `http://127.0.0.1:8765/site/` 查看页面。允许未知值；程序通过不表示事实正确或已获授权。[运行与部署](docs/run-and-deploy.md) 区分本地浏览、检查CI与尚未启用的Pages。
