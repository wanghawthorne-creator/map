# Independent rubric v0.1 / 自建评分规则

制定：2026-11-16。仅供个人作品集。**不是 OneForma、Milky Way、Lightspeed 或任一客户的官方规则。** 不推定不同项目有同一量表，未来收到保密指南也不复制进公开仓库。

先声明查询语境、评价时点与评价范围，再分开作相关性和数据准确性判断。不能以未知位置或距离近直接推定最相关，不能用同名代替实体核实。

## Relevance / 相关性

| Code | Meaning |
|---|---|
| R3 | 明确满足所声明的主要实体/功能意图；必要身份与语境有证据支持 |
| R2 | 主要意图部分满足，存在有证据可说明的实质不足 |
| R1 | 只满足次要或宽泛关联，不能完成主要意图 |
| R0 | 有充分证据表明不满足所声明意图 |
| U | 缺少足以判断实体/意图关系的证据，暂不打数值分 |

R3不自动保证所有准确性维度正确。例如C01仅对报道所指历史实体的名称/功能匹配给R3，今天的导航可用性为U。若查询明确“现在营业/怎么去”，这些条件成为主要意图，不能继续沿用历史范围的R3作为该查询的总判断。

## Attribute accuracy / 属性准确性

分别记录 name、address、category、pin；需要时另记current_operation：

- **S (supported)**：所述范围和时点有明确来源支持，注明是报道、观察、回忆或推断，不等于官方登记或当前事实。
- **C (contradicted)**：有直接反证，附冲突字段与证据；两个来源不同先保留冲突，不能自动选一个判错。
- **U (unable to verify)**：证据缺失、过时、分辨率不足或彼此冲突尚未解决。
- **NA**：该维度确实不适用，并解释原因；缺少坐标使用U，不能用NA隐藏。

不把U当0，不将R分数与属性S/C相加，不生成总分、客观准确率或成功率。日后重复自评只能反映过程一致性，不能证明真实性；如有独立复核，需披露人选、共同证据、独立性和分歧处理。
