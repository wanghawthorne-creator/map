## 可确认结论与未决条件

- 目前最直接对应本作品集的是 **Local Maps Search Evaluator / Milky Way**，其次为 **Local Search Quality Evaluator / Lightspeed**。此次未找到足以确认“当前面向中国开放的专门地图数据标注或POI标注职位”的官方招聘证据；不能用泛标注项目补足该结论。
- **10小时／20小时冲突尚未解决。**项目详情与招募落地页均为官方，但适用范围和更新时间不明。不能任选一个数字作为统一要求；申请时须核对具体地区的账户项目条款。
- 两个地图相关项目的公开详情没有将GIS或编程列为明确必备条件；地图招募FAQ进一步说明无需既有地图或技术经验。因此，本作品集应以地方知识、证据核查与清晰判断为重点。Leaflet、GeoJSON、Python等实现工具不能直接写成申请者已经独立掌握的技能。
- 官方页面要求的**五年居住**，不能由在大理开展田野观察、志愿活动或访谈的经历直接证明，更不等于“在大理田野五年”。申请者是否符合所选地区的实际居住条件仍需单独确认；本作品集不作资格承诺。
- 公开招聘文字说明了任务方向，但本次**未获取可用来复现官方评估的完整评分量表**。作品集使用可解释的自建规则，相关性与名称、地址、类别、点位准确性分别判断；这不是 OneForma 官方评分体系，也不证明通过认证或达到官方质量标准。
- 页面所示开放状态只反映本次公开阅读。具体资格、可用任务、认证流程及适用条款，以申请时账户内的项目要求为准。

## 对最小可行版本的影响

先完善**一条可追溯地点记录和一个完整案例**，展示能核实什么、不能核实什么及判断理由。材料允许后，再扩展到五个核心案例及轻量可浏览地图。缺少可信坐标的地点保留在待核查记录中；不为填满地图而添加点位。
